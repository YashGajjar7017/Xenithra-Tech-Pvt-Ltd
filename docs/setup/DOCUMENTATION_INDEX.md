## 🛠️ Common Workflows

### Workflow 1: "I got an error"

1. Check console (F12)
2. Search [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) for your error
3. Follow solution steps
4. Check [DEBUG Checklist](./TROUBLESHOOTING.md#debug-checklist)

### Workflow 2: "Component not displaying"

1. Read [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) - Issue 4
2. Check [VERIFICATION_CHECKLIST.md](./VERIFICATION_CHECKLIST.md) - File Structure
3. Verify component is exported properly
4. Check imports in parent component

### Workflow 3: "I want to add a new component"

1. Review [COMPONENT_SETUP_SUMMARY.md](./COMPONENT_SETUP_SUMMARY.md) - "Component Features"
2. Study existing component in [renderer/src/components/](./renderer/src/components/)
3. Follow same pattern: Component.jsx + Component.css
4. Add import in App.jsx or parent component
5. Use component: `<ComponentName />`

### Workflow 4: "I want to understand the architecture"

1. Read [ARCHITECTURE_VISUAL_GUIDE.md](./ARCHITECTURE_VISUAL_GUIDE.md) - "Complete File Tree"
2. Study "Component Hierarchy" section
3. Review "Component Dependencies" section
4. Check "Data Flow" section

### Workflow 5: "I want to start development"

1. Run `npm install` (if needed)
2. Run `npm run dev`
3. Open http://localhost:3000/editor
4. Start editing components in renderer/src/
5. Changes reload automatically
